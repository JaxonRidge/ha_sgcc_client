# ⚡ 震雷定极：电量信息智能推演 (SGCC Client)

### 觉得盯着电费数字很枯燥？那是因为你还没开启这套“电力波导”推演引擎。

#### 这是一套深度复刻“SGCC”底层逻辑，并融合了大六壬三传四课与现代能量频谱的智能占测集成。

#### 所有的余额、日用电、月账单，并非简单的抓取，而是经由六壬课式起局、雷部类神映射、再还原至数字实体的。主打的就是一个“法度严明”的实时监控状态。

---

## ✨ 为什么它与众不同？

**雷部驱动：离火化电**
我们不搞简单的 API 搬运。系统以六壬“月将加时”布天盘，取震、离之卦象定电力旺衰。
*   取**财爻**定账户虚实，取**玄武**防盗漏。
*   重点是：**核心逻辑加壳封装**，内存级动态解密，确保推演路径不被轻易勘破，定力稳固。

**三阶门卫：因果防御**
内置严密的“三阶门卫”拦截机制：
1.  **安检层**：全量有效缓存前置拦截，非必要绝不惊动后台。
2.  **审计层**：严格执行 24 小时 3 次联网限流，遇 **RK001** 自动开启“阶梯式封印”，保护账号安全。
3.  **冗余层**：字段级合并（Field Merge），即便单次推演受扰，也会自动回溯历史有效格局，确保实体永不掉线。

## 🔭 推演规制（核心逻辑）

*   **起课法则：** 依占时起局，立四课、发三传。以账户为“年命”，定夺当季电力盈亏。
*   **类神映射：**
    *   **财爻** → 账户余额（定财宫盈虚）
    *   **震卦/子孙** → 每日电量（定能量流转）
    *   **库神/父母** → 历史账单（定往期归档）
*   **持久化仓库：** 支持文件系统存储，确保重启后，所有的风控封印状态与能量缓存皆能“累世而传”。

---

## 📊 核心电力实体（三传定象）

针对每个户号，系统将演化出四尊核心类神实体：

| 实体名称 | 状态 (State) | 关键属性 (Attributes) |
| :--- | :--- | :--- |
| **账户余额** | 实时余额数值 | 地址、户名、预计可用金额、年度用电汇总 |
| **本月累计电量** | 本月 1 号至今累计 | **40天日电量趋势**、峰谷平细项、统计截止日期 |
| **月度用电量** | 上月结算电量 | 历史月度账单列表 (最近一年) |
| **年度总用电量** | 本年累计用电 | 年度总支出、查询年份 |

## 📦 怎么装？

### 方法一：通过 HACS 安装（推荐）
1.  在 HACS 的 "集成" 部分，点右上角三点菜单。
2.  选 "自定义存储库"。
3.  输入地址：
  ```yaml
  https://github.com/JaxonRidge/ha_sgcc_client
  ```
4.  类别选 "集成"，点 "添加"。
5.  找到 "SGCC Client" 进行安装并重启。

### 方法二：手动安装
1.  下载最新压缩包。
  ```yaml
  https://github.com/JaxonRidge/ha_sgcc_client
  ``` 
2.  解压，把 `sgcc_client` 文件夹放入 Home Assistant 的 `custom_components` 目录。
3.  重启 Home Assistant。
